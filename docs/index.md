## Getting started

1. Download the latest release from the [releases page](https://github.com/HakkuPantsu/poe-kitten/releases)
2. Run it — the portable `.exe` needs no install
3. Launch Path of Exile 2 once so it creates its log files
4. Open the dashboard with `Shift` + `Space`, go to **Settings**, and turn on **Read client log**

See [Quick Start](/quick-start) for the full walkthrough.
