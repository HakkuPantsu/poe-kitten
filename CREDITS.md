# Credits

POE Kitten is a fork of [Exiled Exchange 2](https://github.com/Kvan7/Exiled-Exchange-2),
which in turn descends from [Awakened PoE Trade](https://github.com/SnosMe/awakened-poe-trade).

A very large portion of the price checking, item parsing, trade API and data
pipeline code in this project was written by the people below. Their work is the
foundation POE Kitten is built on, and this file exists so that credit survives
independently of the git history.

## Upstream authors

- **[SnosMe](https://github.com/SnosMe)** — Awakened PoE Trade. The original
  overlay this lineage descends from, and the largest single body of work here.
- **[Kvan7](https://github.com/Kvan7)** — Exiled Exchange 2. The PoE2 fork that
  POE Kitten is directly based on.
